# Court Value 1.1: worked examples

Generated by `worked_examples.py` from the declared input snapshot and the release-candidate outputs. Each production step below is recomputed from raw season totals, independently of the engine; league-season reference statistics (means and population SDs), tier assignments and appearance-game MOV are read from the release files; team defensive Z is read from the release for player examples and recomputed from raw totals for the team example. The script fails if any recomputed score differs from the published value by more than 1e-9. Values are shown to four decimals; calculations use full precision.
